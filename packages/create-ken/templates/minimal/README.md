# ken

A ken root: a knowledge base over the repos under `.repos/`, one section per folder. Say
here what it covers and name its few evergreen pages. The repos are `ken repos`; recent
changes are in `log.md`.

- [flows](flows/README.md): what happens across repos, end to end. 0 pages.
- [playbooks](playbooks/README.md): how to get a job done, step by step. 0 pages.
- [decisions](decisions/README.md): why it is this way, one decision a page. 0 pages.
