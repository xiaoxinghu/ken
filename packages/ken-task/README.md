# @unclex/ken-task

Plain-text tasks in one folder of a ken root, one file per task, the file's path as its
identity, a branch and worktree per task. `ken` finds it on `PATH` as `ken-task`, so it
reads as `ken task claim`. Built on `ken config`, `ken which`, `ken path code` and
`ken get -b`, and runs git for the rest. See `docs/ken-task.md` at the repo root.
