# @unclex/ken-task

Tasks and notes as denote-named plain-text files in a volume, a branch and worktree per
task. `ken` finds it on `PATH` as `ken-task`, so it reads as `ken task claim`. Built on
`ken path code`, `ken get -b` and `ken which`, and runs git for the rest. See `docs/prd.md` at the repo root.
